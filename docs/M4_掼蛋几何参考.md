## 2. Canvas 手牌布局（我方，源码公式）
```
断点(按容器宽 w)：
  w < 360 : cardW=38  cardH=54  gap=10
  w < 480 : cardW=44  cardH=62  gap=12
  否则     : cardW=50  cardH=70  gap=14        ← 720 宽设备落这档
手牌(不重叠！按 gap 平铺):
  totalWidth = (n-1)*gap + cardW
  startX = (W - totalWidth)/2
  baseY  = H - cardH - 15
  第 i 张: x = startX + i*gap, y = baseY (选中时 y -= 18)
点击命中(getClickedCardIndex): 从右往左遍历, 命中矩形 [x, x+cardW]×[y, y+cardH]; 
  → 自然语义: 点相邻缝隙会命中**更靠右**那张; 选中牌抬升 18px 后其原位置让给左邻
```
**27 张手牌不重叠**（gap 12 → 27 张总宽 356px < 720）→ 识别比斗地主轻松（无严重重叠）。
