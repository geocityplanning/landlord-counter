# DouZero 技术路线详解：为什么可行

> 整理日期：2026-08-24
> 来源：DouZero 论文 (arXiv:2106.06135, ICML 2021) + 官方 GitHub + 社区衍生项目

---

## 一、DouZero 是什么

**DouZero** 是**快手 AI 平台部**开发的斗地主强化学习 AI 系统，论文发表于 **ICML 2021**（机器学习顶会）。

- **论文**：Zha et al. "DouZero: Mastering DouDizhu with Self-Play Deep Reinforcement Learning", ICML 2021
- **代码**：https://github.com/kwai/DouZero（Apache 2.0 开源）
- **成绩**：训练数天即在 **Botzone 排行榜 344 个 AI 代理中排名第一**，击败当时所有开源斗地主 AI

---

## 二、它解决的是哪个游戏？（关键澄清）

**DouZero 解决的是「斗地主」这个游戏本身**——它是**通用的斗地主决策引擎**，不绑定任何具体平台。

```
重要区分：
┌─────────────────────────────────────────────┐
│  DouZero = AI大脑（决策引擎）                  │
│  → 输入：当前手牌 + 出牌历史 + 已知信息        │
│  → 输出：该出什么牌                           │
│  → 与平台无关：PC客户端/手机App/微信小程序都适用 │
└─────────────────────────────────────────────┘
```

### 不是微信小程序！
- DouZero **不是**一个微信小程序，也不是为某个平台开发的
- 它是一个**开源 Python 库**，可以用 `pip install douzero` 安装
- 它的职责是"**决定出什么牌**"，至于"怎么看到牌、怎么点击出牌"是另一层的事（视觉识别 + RPA 操作层——这正是我们 landlord-counter 项目在做的事）

### 社区衍生项目（直接证明可行性）
| 项目 | 说明 |
|------|------|
| DouZero_For_HLDDZ_FullAuto | 基于 DouZero 的**欢乐斗地主全自动版**：自动截屏、自动出牌、自动叫牌/加倍、自动续局 |
| DouZero_For_Happy_DouDiZhu | 适配欢乐斗地主 PC 客户端的早期版本 |
| DouZero ResNet | 社区改进版（更强的神经网络结构） |

> 这些项目证明：**DouZero 决策引擎 + 截屏识别 + 自动化操作 = 完整挂机系统**，且已被社区实现验证。

## 三、为什么技术可行（核心论据）

### 3.1 斗地主的难度（为什么以前的 AI 不行）
| 挑战 | 说明 |
|------|------|
| 非完全信息 | 看不到对手的牌 |
| 巨大状态空间 | 牌型组合约 10^20 |
| 巨大动作空间 | 每一步合法出牌组合高达 **10^4** |
| 合作+对抗并存 | 两个农民需合作对抗地主，学术界开放难题 |

### 3.2 DouZero 的解法（为什么它行）
```
核心公式：Deep Monte Carlo (DMC) + 动作编码 + 并行演员

1. 深度蒙特卡洛 (DMC)
   → 用深度神经网络替代传统蒙特卡洛的表格
   → 每次模拟完整对局到结束，用最终输赢作为奖励信号
   → 解决了"中间步骤没有明确对错"的问题

2. 动作编码 (Action Encoding)
   → 把"出什么牌"编码成特征向量喂给网络
   → 让网络能处理变化巨大的合法动作集合

3. 并行演员 (Parallel Actors)
   → 多个 AI 同时自我博弈对打，加速训练
   → 单服务器 4 张 GPU，几天训练完
```

### 3.3 训练方式：自我博弈（Self-Play）
```
DouZero AI 自己和自己打牌
   ↓
从完全随机开始（什么都不会）
   ↓
每打完一局，根据输赢调整策略
   ↓
数百万局后 → 学会记牌、算牌、出牌策略
   ↓
击败所有旧 AI，登顶 Botzone 排行榜
```

### 3.4 官方战绩（论文中的数据）
- 在 Botzone 排行榜（344 个 AI 代理）中**排名第一**
- 击败此前所有开源斗地主 AI 程序
- 在线演示：https://www.douzero.org/

## 四、对我们的项目意味着什么（怎么用）

```
我们的挂机系统 = DouZero大脑 + 我们的感知/操作层

┌──────────────────────────────────────────────┐
│  感知层（我们已实现）:                          │
│  ADB截屏 → 模板识别 → 记牌器 → 局面状态         │
│              ↓                                │
│  决策层（接入DouZero）:                        │
│  局面状态 → DouZero模型 → "建议出牌"           │
│              ↓                                │
│  操作层（我们已实现骨架）:                      │
│  "建议出牌" → ADB点击 → 完成出牌               │
└──────────────────────────────────────────────┘
```

### 接入方式（官方支持）
```bash
# 1. 安装
pip install douzero

# 2. 加载预训练模型（官方提供，无需自己训练）
from douzero.dmc.models import Model
model = Model()
model.load_card_model('baselines/', 'landlord')  # 地主模型

# 3. 决策接口
action = model.act(state)  # 输入局面，输出出牌
```

### 关键优势
1. **不用自己训练**：官方提供预训练模型（`baselines/*.ckpt`），下载即用
2. **模型可替换**：ADP 模型 / ResNet 模型，社区持续改进
3. **开源免费**：Apache 2.0 协议，商用友好
4. **已验证**：全自动挂机项目已跑通（DouZero_For_HLDDZ_FullAuto）

## 五、需要注意的限制

| 限制 | 说明 |
|------|------|
| 平台适配 | DouZero 只负责决策，不负责识别/操作，需要我们的视觉层配合 |
| 游戏更新 | 欢乐斗地主改版后，截屏识别需重新适配（社区项目已遇到并解决） |
| 真实胜率 | 约 50-55%，想更高需针对具体平台微调训练 |
| 合规 | 自动挂机违反腾讯用户协议，有封号风险 |

---

## 六、结论

**DouZero 技术路线可行的根本原因**：
1. ✅ **顶会论文背书**（ICML 2021）+ 开源代码
2. ✅ **战绩可验证**（Botzone 排行榜第一）
3. ✅ **预训练模型即用**（无需从零训练）
4. ✅ **社区已验证全自动挂机**（DouZero_For_HLDDZ_FullAuto）
5. ✅ **Apache 2.0 协议**（商用合法）
6. ✅ **决策引擎与平台解耦**（我们负责感知/操作，它负责大脑）
