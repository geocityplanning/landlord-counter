# game_ai/ —— 游戏本体的 AI(原样搬运)

**来源**: `lab/guandan_www/js/{aiLogic.js, gameRules.js}` (我们自己的掼蛋实验游戏)

**为什么搬**: 用户 2026-09-21 ——
> "将游戏的AI复制出来处理一下，放在和RL同样的地位，加同样的护栏那一套东西"
> "这样可以测出来一个东西: 如果自己跟自己打胜率远低于50%，那就是我们的代码里面有拖后腿的代码"

⇒ 把它做成**第二个"脑子"**(决策臂) —— 和 RL 平级:
   · 都只负责"**在这手牌里出什么**" ✓
   · 都走**同一条执行链**: 代价过滤 → 领出兜底 → 出牌前自检 → 身份定位点选 → 真值对账 ✓
   ⇒ 这样 A/B 才公平: 差异只来自"出牌策略", 不来自执行/护栏 ✓

**搬运方式**: 文件**原样复制**(不改写、不翻译 ✗) —— 保真第一 ✓
  由 `game_ai_worker.js`(node 常驻进程)驱动, Python 侧用 `game_ai.py` 调用 ✓
  每次问一句、答一句(JSON 行) ⇒ 单次约 1ms ✓

**与 lab 原件的同步**: 改动 lab 的这两个文件后, 记得同步到这里 ✓
   (两边不一致就失去"对照组"的意义了 ✗)
