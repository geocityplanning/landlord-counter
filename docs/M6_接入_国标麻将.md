# M6 第二例：中式麻将（国标/中国标准麻将）接入实录

> 目的：验证"加一款新游戏 = 写一个适配器"。第一款是日式立直麻将（電脳麻将），本篇是**中式规则**的第二例。
> 选型：`guming-learning/guobiao-majiang`（网页版国标麻将，Node+express+socket.io，服务器权威）。
> 详细选型理由/许可说明见 `reference/guobiao-majiang/UPSTREAM.md`（⚠️ 未声明 LICENSE，仅内部研究/演示）。

## 一、已验证的通路（2026-09-14 实测）

| 环节 | 结论 | 证据 |
|---|---|---|
| 起服务 | `bash tools/serve_guobiao.sh 8125` → `http://172.18.0.1:8125/` | HTTP 200，中文页面 |
| 设备方向 | **必须横屏**（游戏要求）→ `settings put system user_rotation 1` | `mCurrentOrientation=1`，视口 1184×720 |
| 无障碍树 | **完整可读**，且暴露 **DOM id 到 `resource-id`** | `table-screen / topbar / tb-room / tb-round / tb-turn / tb-wall / tb-hint / advice-float / close-room-btn / leave-btn / sound-btn` |
| 登录 | **输入昵称 + Enter 提交**（`#name-input` 的 keydown Enter → 进入大厅） | 实测"输入 bot + Enter" → 游戏大厅 |
| 建/进房 | **Tab 聚焦 + Enter 激活**（Tab 次数：取消=1、创建=2） | 实测创建出"房间 1001" |
| 补机器人 | `＋ 添加机器人` 每按一次加一个 → 凑满 4 人 | 机器人2/3/4 依次加入 |
| 准备开局 | `准备` → `东圈·第1局 · 8番起 / 余 86 张 / 轮到：bot（东）/ **该你出牌**` | 实测开局成功 |
| 触控 | **本页触控是好的**（与日式那款不同） | 点「隐藏提示」→ 按钮变「显示提示」，帧差 2.28 |

### 关键差异：中式这款对自动化友好得多

- **回合信号是白纸黑字**：`轮到：X（方位）` + `该你出牌` —— 不用再靠张数 mod 3 猜。
- **牌桌信息齐全**：`余 N 张`（牌墙）、四家点数（`+0`/`±分`）、`东圈·第N局`。
- **番型提示**：服务端下发 `advice {seat, list}` → 前端渲染成"三色三步高 6番·差4"这类候选番（是"离哪个番还差几张"，**不是具体打哪张**）。
- **中文牌名**（万/条/饼/中发白/风/花）→ 若走视觉识别，VLM 读中文比日文省事。

## 二、待解决（下一步）

| 项 | 结果 |

| 出牌执行 | 点最左牌位 (272,620) → **牌墙 53→49（正好一轮四张）** ⇒ 出牌动作生效 ✓ |
| 提示(réponse) | **全中文文本**：`吃 7饼8饼` / `过` 都是可点的 Button ⇒ 应答不需要视觉 ✓ |

### 仍未解决

1. **"打出的是哪张"的身份校验**：我方弃牌区没有文本节点、也没有独立可裁的区域（上方是中央牌河，混在一起读不干净）。
   → 方案：按**自己的弃牌槽位**（棋盘四周属于我方的那条）动态定位后再读；或用"手牌前后帧差"确认减少的那张与读数一致。
2. **吃碰杠和应答**：文本已可读（`吃 7饼8饼`），需实测点击是否生效 + 记入决策。
3. **结算**：局末番种/分数展示 → 用 `tb-round`（局名推进）或分数变化判局（同日本麻将的双判据思路）。
4. **决策策略**：当前只有占位策略（如"打最左/刚摸的牌"）；要打得好需接中式麻将 AI（另立课题）。

## 三、可复用的通用件（本周新增，已入平台层）

- `platform/keyboard.py`：**无触控/弱触控环境的通用键盘驱动**
  - `activate(dev, a11y, 文字)`：Tab 逐个聚焦，命中目标文字后按 Enter（实测可激活任意 `<button>`）
  - `focused_texts(a11y)`：读"键盘焦点"节点 —— ⚠️ 无障碍树里**会有多个 `focused=true`**（WebView 容器 + 真控件），必须过滤容器类，否则永远匹配不上
- `platform/a11y.py` 增强：`Node.focused`、`A11y.focused()`、`A11y.any_node(文字)`（按文字找节点，不依赖控件类）
