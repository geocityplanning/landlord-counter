# M5 演示包（云手机 AI 托管 · 掼蛋/斗地主）

> 面向厂商演示的一页材料。核心卖点：**在真实云手机里"看图操作"的手机游戏 AI 托管**——不注入游戏、不改客户端、不接 SDK，纯视觉 + 点击，天然适配各种手游。

## 一、一句话能力

在云手机（Android 容器）中运行真实手游，AI 全程"看画面 → 认牌/认界面 → 决策 → 点屏幕"，**无人值守连续对局**，并自动记录战绩。

## 二、演示怎么做（一键）

```bash
# 掼蛋: 进桌 + 托管 N 分钟 + 录屏（默认 6 分钟、开录屏）
bash tools/demo_guandan.sh 6 1 0        # 提示驱动模式(最稳)
bash tools/demo_guandan.sh 6 1 1        # 自研决策模式

# 斗地主(DouZero 托管)
python3 /root/.hermes/scripts/ddz_prep.py
STATS_FILE=/tmp/stats_demo.csv DOUZERO=1 PYTHONPATH=src \
  /usr/local/lib/hermes-agent/venv/bin/python3 -u -m landlord_counter.tools.auto_play
```

产物：
- 录屏 `mp4`（逐帧截屏 5fps 合成，带说明字幕）→ `docs/media/`
- 战绩 CSV（每局结算：时间、局号、胜负、模式标签）
- 日志（含每次决策与执行回执）

## 三、演示脚本（讲述线）

1. **开场**：手机（云机）放在桌上，屏幕上真人在玩的效果——但是**没有人在操作**
2. **看**：AI 读手牌 → 展示读牌结果与画面一致（可暂停对照）
3. **想**：AI 决策（可切换"自研规则+AI"或"借游戏自带提示"两种模式）
4. **做**：点选牌 → 出牌；回合外自动"不出"
5. **闭环**：一局结束 → 结算 → 自动开下一局；夜间连续跑，次日给战绩报表
6. **数据**：头游率/升级率、每局耗时、决策次数

## 四、已验证指标（2026-09-11）

| 指标 | 数值 | 说明 |
|---|---|---|
| 连续对局 | 81 局/夜（首夜，3 个窗口失效） | 窗口修复后应 6/6 窗口出数据 |

| 单局耗时 | 约 2 分钟 | 掼蛋 4 人局 |
| 决策/执行 | 每次点击带**回执校验** | 未生效自动重试 / 回落，零卡死 |

## 五、技术要点（可讲给技术方）

1. **纯视觉识别**：VLM（DeepSeek 视觉）+ 源码几何/色块 + 帧差，识别手牌与桌面牌；抗 UI 差异
2. **零注入**：不 hook、不读内存、不模拟协议——操作方式与真人一致（点击坐标）
3. **多策略决策**：规则引擎（掼蛋规则全移植 + 75 项测试）、开源 AI（掼蛋）、DouZero（斗地主）
4. **可靠性工程**：回合判定双帧稳定、出牌回执校验、回落链、看门狗自愈（页面卡死自动重开）、窗口制夜跑
5. **成本**：识别按需调用（画面变化才读），单局约 ¥0.002-0.01
