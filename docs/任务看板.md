## 验收口径（写死，避免再飘）

| 指标 | 定义 | 门槛 |
|---|---|---|
| **操作准确率** | 「决定出的牌」== 「实际打出的牌」的比例（identity 级）| **≥99%**（四臂对比的前置） |
| 执行落实率 | 决策里没走兜底的比例 | ≥95% |
| 决策层对比 | 执行条件相同的两臂对比（ours_direct vs ours_rl）| 每臂 ≥100 局 |
| 队伍指标 | 头游率 / 双上率 / 被双下率 / 场均升级 / 队友名次 | 分臂统计 |
| 数据可追溯 | 每手出牌可查（谁/什么牌/何时）+ 池子余牌 | 接口可用 |
